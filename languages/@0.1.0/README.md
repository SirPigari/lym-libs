# Languages.lc

This is a collection of language defines for Lucia. It translates keywords and types to other languages, allowing you to write Lucia code in a different language.

## Supported languages

| Language            | Code    | File                                           |
| ------------------- | ------- | ---------------------------------------------- |
| Czech               | `cs-CZ` | [czech.lc](./czech.lc)                         |
| English (UK)        | `en-GB` | [english_uk.lc](./english_uk.lc)               |
| English (US)        | `en-US` | [english_us.lc](./english_us.lc)               |
| Japanese (Hiragana) | `ja-JP` | [japanese_hiragana.lc](./japanese_hiragana.lc) |
| Japanese (Kanji)    | `ja-JP` | [japanese_kanji.lc](./japanese_kanji.lc)       |
| Japanese (Katakana) | `ja-JP` | [japanese_katakana.lc](./japanese_katakana.lc) |
| Japanese (Romaji)   | `ja-JP` | [japanese_romaji.lc](./japanese_romaji.lc)     |
| Slovak              | `sk-SK` | [slovak.lc](./slovak.lc)                       |
